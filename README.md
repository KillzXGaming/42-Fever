# 42-Fever
Simple extractor to dump 42 file from Tennis Fever versions 1.0 and 1.1. 

To use:
- Open the folder of the version you need and copy fst.json to the folder this script is in.
- Put the 42 folder in the same folder this script is in, then run it. It will make 42_output output folder.

Modding the file is not planned.
